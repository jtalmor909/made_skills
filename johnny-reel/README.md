# johnny-reel

A 15s vertical (1080×1920) personal intro reel built with **HyperFrames**: HTML + GSAP, rendered to MP4.

`johnny-reel.mp4` is the rendered output.

## Beats
| Time | Beat | Device |
|---|---|---|
| 0–1.6s | **Hello.** typed with a caret | AE-style comp: grid, guides, timecode, timeline ruler with a live playhead |
| 1.6–4.1s | Silhouette drawn as a **bezier path** (vertices and handles), then filled; name slams in | vector trace of the real photo |
| 4.1–6.4s | *I make pixels* **move.** | hand-tuned inertial bounce (squash → elastic settle) |
| 6.2–7.3s | Keyframe-diamond double wipe into night | the ruler's keyframe becomes the transition |
| 7.1–11.8s | **The climb**: Motion Designer → Motion Director → Creative Technologist → Systems Architect → Animation Engineer → **Head of Motion** | slot roll that speeds up, an altitude meter, rising-pitch SFX, spark burst at the top |
| 11.8–15s | Iris-out end card: avatar, name, title, CTA | the CTA arrow keeps moving while it rests |

## Edit & render
```bash
npm install
npx hyperframes preview                    # studio
npm run render                             # -> out/johnny-reel.mp4
# change name / final title without touching code:
npx hyperframes render . -o out/alt.mp4 --variables '{"lastName":"Talmor","finalLead":"Director of","finalTitle":"Motion"}'
```
Variables: `firstName`, `lastName`, `finalLead`, `finalTitle`, `accent`.

## Assets
- `assets/johnny.png`: silhouette cut from the photo (rembg `u2net_human_seg`)
- `assets/silhouette.js`: traced vector contour and bezier vertices used for the draw-on
- `assets/sfx.wav`: generated by `tools/make_sfx.py` (deterministic, license-free, transients aligned to events)
- Fonts: Inter Tight, Instrument Serif, JetBrains Mono (OFL, vendored)
